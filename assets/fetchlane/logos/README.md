The Fetchlane mark as fixed-colour SVGs for use outside the app (installer, Start menu, website, README).

- `fetchlane-mark-dark.svg` — teal `#3cc7b8` tile, glyph `#06201d`; for dark backgrounds.
- `fetchlane-mark-light.svg` — teal `#0d7f75` tile, white glyph; for light backgrounds.
- Inside the app draw the mark with `Fetchlane.mark(size)`, which binds to `accent` / `on-accent` and follows the theme.
