Subtle file-type glyph for rows and the details panel, `Fetchlane.fileIcon(filename, size)`.

- Mapped from the extension: disc (iso, img, vhdx), archive (zip, gz, 7z), app (exe, msi), video, audio, image, document (pdf, pptx, docx), data (csv, parquet, json), other.
- Always `ink-subtle`, decorative (`aria-hidden`); the filename carries the information.
