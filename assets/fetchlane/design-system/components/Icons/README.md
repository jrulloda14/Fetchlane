The line icon set used everywhere in the app, exposed as `Fetchlane.icon(name, size)`.

- 24-unit grid, 1.6 stroke, round caps and joins, `currentColor`; draw at 16 px (12–14 px inside status labels and hints, 20 px in Settings rows).
- Icons always sit beside a word or carry an `aria-label` + tooltip. Never rely on an icon alone to communicate status.
- Status icons are fixed: down = downloading, clock = queued, pause = paused, circular arrow = retrying/retry, alert circle = failed, check circle = completed, stop square = cancel.
