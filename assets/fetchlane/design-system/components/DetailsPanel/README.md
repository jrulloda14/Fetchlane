Right-side panel (340 px) describing one download, opened with Enter, double-click, Ctrl+I or the Details menu item.

Consumer provides: the download record; whether URL parameters are revealed; whether the optional speed history is expanded.

- Header: file icon, full filename (wraps), lock/globe + hostname, close (Esc).
- Body: status label; big percentage and "x of y" (or bytes so far when the size is unknown); the explanation block; a grid of Speed, Time left, Elapsed, Size, Started, Resumable — unavailable values show "—" with a short reason.
- Saved to (path + Show in folder) and Source (redacted parameters, reveal toggle, copy full link).
- Speed history is collapsed by default and labelled optional; nothing in the panel depends on it.
- Footer: the actions for the current state — Pause/Cancel…; Resume; Start now; Retry now/Pause; Retry (+ Change folder…); Restart download…; Open file/Show in folder — plus overflow.
- Selection follows: with the panel open, moving the focused row updates the panel.
