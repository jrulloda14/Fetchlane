Title bar and status bar framing the window.

- Title bar: 32 px, `surface-000`, mark + "Fetchlane" in `text-caption`; draggable; Windows caption buttons (46 × 32; close hovers `caption-close`). No menus or search in the title bar.
- Status bar: 28 px summary — downloading/retrying counts, total speed, queued count, free space on the default drive, and the simultaneous limit as a link to Settings. It is `role="status"` with live announcements off (values change every second).
