The Fetchlane mark and lockup: a file travelling down a dashed lane into a tray.

- Draw it with `Fetchlane.mark(size)`; it uses `accent` and `on-accent`, so it follows the theme. Outside the app, use `assets/Logos/fetchlane-mark-dark.svg` or `-light.svg`.
- Sizes: 16 (title bar), 24, 32, 48, 64, 256 (installer, Start menu). Keep 1/8 of its size clear on every side.
- Lockup: mark + "Fetchlane" in `font-display` 600, tagline "Your downloads, in order." in `ink-muted`.
- Don't recolour the tile outside the teal pair, add effects, or rebuild it as an outline.
