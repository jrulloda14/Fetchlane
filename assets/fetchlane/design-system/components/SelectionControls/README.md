Checkbox, toggle switch, segmented control and number box.

- Checkbox: row selection and opt-in options. Supports checked, unchecked and mixed (select-all with a partial selection). 18 px, 16 px in compact rows.
- Toggle: settings that take effect immediately (Retry automatically). Always followed by "On"/"Off" text.
- Segmented control: one choice from 2–3 (Theme, List density). The chosen segment gets `surface-selected`, bold label and an `accent` underline — not colour alone.
- Number box: bounded integers (Maximum simultaneous downloads 1–10, Attempts 1–10). Steppers disable at the limits; typing is allowed and clamped on blur.
