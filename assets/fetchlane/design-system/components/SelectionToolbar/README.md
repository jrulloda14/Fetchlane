Contextual toolbar that replaces the list heading whenever one or more rows are selected.

- Starts with a tri-state checkbox (select all in this list / clear) and "n selected" (announced politely).
- Each action shows the count of selected downloads it applies to; zero disables it. Pause skips downloads whose server can't resume.
- Move to top appears only when queued downloads are selected. Remove from list… always confirms and never deletes files by default.
- Clear selection (Esc) on the right. At narrow widths it becomes icon-only with an accessible name.
