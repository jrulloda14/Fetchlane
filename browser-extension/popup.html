Checking…

The browser stops its own download and sends only the link to Fetchlane. Your sign-in, form data and one-time links don’t go with it, so some downloads can fail in Fetchlane.

If you choose Cancel in Fetchlane’s Add download, nothing is downloaded; start the download in the browser again.

If Fetchlane can’t be reached, the browser starts the link again, which may not work for links that only work once.

With catching on or off, right-click a link and choose Download with Fetchlane to send one link, including magnet links. Fetchlane can’t use your browser’s sign-in, so a download that needs it may fail there.
